# B站关注管理助手

一个 Tampermonkey 用户脚本，帮助你高效管理 B 站关注列表。  
支持自动加载、筛选排序、批量取关、导入导出等功能，并针对大量关注进行了性能优化。

## ✨ 功能特色
- **自动加载**：打开页面即自动分批加载所有关注，实时显示粉丝数、关注日期、最后动态日期。
- **筛选排序**：
  - 按粉丝数范围、未更新天数筛选
  - 点击表头可按任意列排序（粉丝数、关注日期、最后动态日期）
- **批量取关**：勾选 UP 主，一键批量取关，并显示进度条。
- **导入/导出**：支持 CSV 格式的导入导出，方便备份或合并关注列表。
- **停止加载**：加载过程中可随时停止，避免长时间等待。
- **高速加载**：并发请求，每页 40 个，间隔 80ms，实测支持 4000+ 关注流畅运行。

## 📥 安装方法
1. 确保浏览器已安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展。
2. 点击以下链接安装脚本（如果浏览器提示，请确认安装）：  
   `https://github.com/xycachen/bilibili-follow-manager/blob/main/bilibili-follow-manager.js`  
3. 打开 B 站关注页面，例如：
   - `https://space.bilibili.com/你的UID/fans/follow`
   - `https://www.bilibili.com/account/following`
   
   右侧会出现悬浮面板，自动开始加载数据。

## 🚀 使用说明

### 1. 加载数据
- 打开页面后，脚本自动开始分批加载，底部进度条显示进度。
- 如需手动重新加载，点击「🔄 重新加载」按钮。
- 加载过程中可随时点击「⏹️ 停止加载」。

### 2. 筛选与排序
- **粉丝数范围**：输入最小/最大粉丝数，点击「筛选」即可。
- **未更新天数**：输入天数（例如 30），筛选出最后动态距今 ≥ 30 天的 UP 主。
- **重置**：清空所有筛选条件，恢复显示全部。
- **表头排序**：点击“粉丝数”、“关注日期”、“最后动态日期”表头，可切换升序/降序。

### 3. 批量取关
1. 在表格中勾选要取关的 UP 主（表头全选框可一键全选/取消）。
2. 点击「🗑 一键取关选中」。
3. 确认后，底部显示取关进度条，完成后提示成功/失败数量。

### 4. 导入 / 导出
- **导出 CSV**：将当前筛选后的列表导出为 CSV 文件（包含 `mid`、UP主、粉丝数、关注时间戳、最后动态时间戳），可用于备份或数据分析。
- **导入 CSV**：选择之前导出的 CSV 文件，脚本会合并数据（自动去重），适用于恢复备份或合并不同账号的列表。

## ❓ 常见问题

### Q: 加载失败或数据不显示？
- 请确保已登录 B 站，且当前页面是关注列表页。
- 如果网络不稳定，可以尝试刷新页面重试。
- 若遇到大量请求失败，可适当调低脚本开头的 `CONCURRENT_LIMIT`（例如改为 2）或增加 `REQUEST_DELAY`（例如 150）。
- 查看浏览器控制台（F12）是否有错误信息，并反馈给开发者。

### Q: 导出时页面跳转？
- 脚本已使用 `GM_download` 方式，正常情况下会弹出下载窗口。如果仍跳转，可能是 Tampermonkey 版本问题，请确保脚本头部已包含 `@grant GM_download`。

### Q: 关注数量很多，加载很慢？
- 脚本已采用并发加载，每页 40 个，间隔 80ms。如果您的关注数超过 2000，可以尝试将 `CONCURRENT_LIMIT` 调至 5，但请注意 B 站风控。

### Q: 为什么最后动态日期显示“无动态”？
- 这是正常的，表示该 UP 主近期没有任何动态（包括视频、转发等）。

## 🛠️ 自定义配置
脚本开头有一个 `CONFIG` 对象，您可以按需调整：

```javascript
const CONFIG = {
    PAGE_SIZE: 40,               // 每页加载数量
    CONCURRENT_LIMIT: 3,        // 并发请求数（过高可能被风控）
    REQUEST_DELAY: 80,          // 每个请求后的额外等待时间（毫秒）
    REQUEST_TIMEOUT: 8000,
    BATCH_RENDER_SIZE: 10,      // 每多少个 UP 主渲染一次表格
};
```
